# 11.05 · 生日快乐

一个为女朋友准备的生日惊喜网页。灵感来自「弹窗式朋友圈祝福」：满屏粉色、奶油色的小提示窗，每一扇都藏着一句悄悄话。关掉它们之后，先看看「我们的故事」，再许愿、吹蜡烛、扭个礼物，最后拆开一封信。

**纯静态页面，无任何外部依赖，双击 `index.html` 就能打开。**

## 怎么打开

1. 直接双击 `index.html`（推荐 Chrome / Edge / Safari）。
2. 点击「打开礼物」，音乐和祝福会一起开始。
3. 小窗可以拖动，也可以关掉；在桌面端，点标题栏的 `—` 可以收起，点 `□` 可以放大。
4. 点「看看我们的故事」→ 看完时间线点「许一个愿望」→「吹灭蜡烛」→ 扭蛋礼物 → 收到信。

> 音乐需要一次点击才能播放（浏览器的自动播放限制）。如果没听到，检查一下设备音量。

## 把它变成“只属于她”的

### 1. 名字（最快的方式）

在网址后面加上 `to` 和 `from` 两个参数即可，不用改代码：

```
index.html?to=小满&from=阿泽
```

- `to`：她的名字，会出现在信的称呼、`TO.` 和浏览器标题里。
- `from`：你的名字，会出现在 `FROM.` 和落款里。
- 不加参数时，默认是「宝贝」和「我」；只加一个也可以。

部署到网上后，把链接改成 `https://你的域名/?to=她的名字&from=你的名字` 发给她就行。

### 2. 祝福语

打开 `js/main.js`，找到 `const NOTES = [...]`，每一项是一扇小窗：

```js
{ e: '🌷', t: '今天要开心哦', c: 'blush' }
```

- `e`：标题栏的小图标
- `t`：窗口里的话
- `c`：配色（`blush` / `butter` / `mint` / `lilac` / `sky` / `peach` / `cream`）

建议保留 12 条左右；桌面会全部出现，手机一次显示 6 条，关掉一条会再补一条。

### 3. 那封信

在 `index.html` 里搜索 `写给你的一封信`，下面就是信的正文。可以自由增删段落，也可以直接换成你想说的话。

落款默认是「爱你的 我」，会被网址里的 `from` 参数替换；信件底部还有日期和 11.05 的火漆印章。

### 4. 日期 / 年份

页面里的 `2026.11.05`、`11.05` 都是直接写在 HTML 里的，搜索替换即可。如果明年还想用，记得把年份也改掉。

### 5. 颜色和字体

`css/style.css` 顶部的 `:root` 里集中放着整套配色：

```css
--rose: #d77d92;
--gold: #c9a45c;
--cream: #fffaf3;
```

字体使用系统自带的宋体 / 楷体 / 苹方，不依赖网络。想换字体，改 `--font-serif`、`--font-hand` 即可。

### 6. 音乐

音乐是浏览器实时合成的八音盒版《生日快乐》，没有音频文件。旋律在 `js/main.js` 的 `MELODY` 数组里，按音名和拍数排列，可以自己改。右上角的音乐按钮可以静音 / 恢复。

### 7. 我们的故事时间线

在 `index.html` 里搜索 `我们的故事`，页面中间有四个 `<li class="milestone">`：

```html
<h3>相遇</h3>
<p class="milestone-date">2026.02.19</p>
<p class="milestone-caption">命运让我们相遇</p>
```

- `<h3>`：阶段名称（相遇 / 相熟 / 心动 / 在一起）
- `.milestone-date`：日期
- `.milestone-caption`：日期下面那行小字
- 顶部的 `02.19 — 05.29` 记得一起改

当前时间线：相遇 `2026.02.19` → 相熟 `2026.04.25` → 心动 `2026.05.08` → 在一起 `2026.05.29`。

### 8. 扭蛋礼物

吹完蜡烛后会进入「生日扭蛋机」，标题是「投下一枚硬币，扭出一个礼物」。

- 九份礼物池：撒娇喊老婆 / 一个爱的亲亲 / 一个爱的抱抱 / 一个大蛋糕 / 帮你吹一次头发 / 认真听你吐槽不顶嘴 / 满足一个小心愿 / 命令我背你一小段路 / 帮你按摩肩颈十分钟
- 一共三次机会，每次随机扭出一份，三份不重复
- 第三份抽完后会出现「收好礼物，去读信」，进入终章
- 也可以点「先跳过，直接看信」直接进入终章

想改礼物内容，在 `js/main.js` 里搜索 `const GIFTS = [`，每一项的 `text` 是奖品文案，`emoji` 是展示图标，`cap` 是扭蛋壳的两个颜色。抽奖次数在 `gachaState` 和 `updateGachaUI` 里通过 `3` 控制。
