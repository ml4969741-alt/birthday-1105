# 11.05 · 生日快乐

一个为女朋友准备的生日惊喜网页。灵感来自「弹窗式朋友圈祝福」：满屏粉色、奶油色的小提示窗，每一扇都藏着一句悄悄话。关掉它们之后，还可以许愿、吹蜡烛，最后拆开一封信。

**纯静态页面，无任何外部依赖，双击 `index.html` 就能打开。**

---

## 怎么打开

1. 直接双击 `index.html`（推荐 Chrome / Edge / Safari）。
2. 点击「打开礼物」，音乐和祝福会一起开始。
3. 小窗可以拖动，也可以关掉；在桌面端，点标题栏的 `—` 可以收起，点 `□` 可以放大。
4. 点「许一个愿望」→「吹灭蜡烛」→ 收到信。

> 音乐需要一次点击才能播放（浏览器的自动播放限制）。如果没听到，检查一下设备音量。

---

## 把它变成“只属于她”的

### 1. 名字（最快的方式）

在网址后面加上 `to` 和 `from` 两个参数即可，不用改代码：

```
index.html?to=小满&from=阿泽
```

- `to`：她的名字，会出现在信的称呼、`TO.` 和浏览器标题里。
- `from`：你的名字，会出现在 `FROM.` 和落款里。
- 不加参数时，默认是「宝贝」和「我」；只加一个也可以。

部署到网上后，把链接改成 `https://你的域名/?to=她的名字&from=你的名字` 发给她就行。

### 2. 祝福语

打开 `js/main.js`，找到 `const NOTES = [...]`，每一项是一扇小窗：

```js
{ e: '🌷', t: '今天要开心哦', c: 'blush' }
```

- `e`：标题栏的小图标
- `t`：窗口里的话
- `c`：配色（`blush` / `butter` / `mint` / `lilac` / `sky` / `peach` / `cream`）

建议保留 12 条左右；桌面会全部出现，手机一次显示 6 条，关掉一条会再补一条。

### 3. 那封信

在 `index.html` 里搜索 `写给你的一封信`，下面就是信的正文。可以自由增删段落，`P.S.` 也在里面。

落款默认是「爱你的 我」，会被网址里的 `from` 参数替换。

### 4. 日期 / 年份

页面里的 `2026.11.05`、`11.05` 都是直接写在 HTML 里的，搜索替换即可。如果明年还想用，记得把年份也改掉。

### 5. 颜色和字体

`css/style.css` 顶部的 `:root` 里集中放着整套配色：

```css
--rose: #d77d92;
--gold: #c9a45c;
--cream: #fffaf3;
```

字体使用系统自带的宋体 / 楷体 / 苹方，不依赖网络。想换字体，改 `--font-serif`、`--font-hand` 即可。

### 6. 音乐

音乐是浏览器实时合成的八音盒版《生日快乐》，没有音频文件。旋律在 `js/main.js` 的 `MELODY` 数组里，按音名和拍数排列，可以自己改。右上角的音乐按钮可以静音 / 恢复。

```
└── README.md
```

## 发布

这是纯静态站点，直接把整个文件夹拖到以下任一平台即可：

- **Netlify Drop**：https://app.netlify.com/drop
- **Vercel**：导入文件夹，Framework 选 Other
- **GitHub Pages**：推到仓库，Settings → Pages 选择分支根目录
- **自己的服务器**：把文件放进任意静态目录

不需要安装依赖，也不需要构建。

## 开发预览

页面支持三个只用于调试的场景参数，方便单独看某一幕：

```
index.html?preview=desktop
index.html?preview=cake
index.html?preview=finale
```

正式发给别人时不需要带这些参数。

## 兼容性

- Chrome / Edge / Safari / Firefox 的现代版本
- 手机端已适配，竖屏体验最佳
- 支持 `prefers-reduced-motion`：系统开启「减少动态效果」时，会关闭彩纸和大部分动画
- 全程离线可用，不请求任何外部图片、字体或音频
